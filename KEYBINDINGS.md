# Keybindings

Generated by `mac-keys --md` from the live configs — do not hand-edit.

**SUPER = Option (⌥)**, matching Omarchy. Caps Lock is also mapped to ⌥ as an optional second Super (tap it alone for Escape).

## Karabiner (modifier layer)

| Keys | Action |
|---|---|
| `Caps Lock (hold)` | SUPER — the modifier every window binding below uses |
| `Caps Lock (tap)` | Escape |
| `Right ⌘` | second SUPER key |
