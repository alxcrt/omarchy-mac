# Keybindings

Generated by `mac-keys --md` from installed defaults and live config files — do not hand-edit.

Window management is macOS's own tiling + Mission Control Spaces (no tiling WM).
Caps Lock is Escape and the right ⌘ is ⌥, remapped by hidutil (`mac-keyremap`).

## Modifier layer (hidutil — see mac-keyremap)

| Keys | Action |
|---|---|
| `Caps Lock` | Escape |
| `Right ⌘` | ⌥  (SUPER) |

## Tiling (Window > Move & Resize)

| Keys | Action |
|---|---|
| `fn ⌃ ←/→/↑/↓` | tile window to a half |
| `fn ⌃ ⇧ ←/→/↑/↓` | arrange this window and the next |
| `fn ⌃ ⌥ ⇧ ←/→/↑/↓` | arrange half + quarters |
| `fn ⌃ F` | fill screen |
| `fn ⌃ C` | centre window |
| `fn ⌃ R` | return to previous size |
| `drag to screen edge` | tile (hold ⌥ while dragging for the preview) |

## Spaces (Mission Control)

| Keys | Action |
|---|---|
| `⌃ 1..9` | switch to Desktop 1-9 (enable with: mac wm --apply) |
| `⌃ ←/→` | previous / next Desktop |
| `⌃ ↑` | Mission Control — add Desktops here with + |
| `drag window to top edge` | then drop onto a Desktop to move it |
